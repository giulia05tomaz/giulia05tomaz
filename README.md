## Projetos em destaque 🚀

### [JusFácil](https://github.com/giulia05tomaz/Jusfacil)

**Full Stack · Next.js · React · TypeScript · Firebase · OpenAI · Python**

LegalTech de portfólio para organizar casos, evidências e minutas com auxílio de IA.

- Autenticação, autorização por caso e triagem conversacional com o JurisBot.
- Processamento de evidências, geração e versionamento de minutas, aprovação e montagem de documentos PDF/Word.
- Contratos de saída estruturada, testes automatizados e regras de acesso do Firestore.

**Status:** em desenvolvimento. Os portais profissionais e alguns formatos de evidência ainda precisam de validação final; o projeto não realiza protocolo automático em tribunais.

### [Automação Social Media com IA](https://github.com/giulia05tomaz/social-media-ai-agent)

**Automação & IA · n8n · Python · FastAPI · PostgreSQL · Docker · OpenAI**

Workflows de criação de conteúdo com identidade visual, revisão humana e rastreabilidade por versão.

- Briefing, copy, legenda, hashtags e geração de imagem com IA.
- Renderer em Python, templates de marca, revisão, aprovação e calendário editorial.
- Integrações de mídia com Cloudflare R2 e publicação via Buffer, com travas para execução controlada.

**Status:** em evolução. A configuração pública começa em modo mock/dry-run; WhatsApp, TikTok e dashboard operacional permanecem no roadmap.

### [GreenMeter Lite](https://github.com/giulia05tomaz/GreenMeter-Lite)

**Full Stack & API · React · TypeScript · Laravel · MySQL · Docker · GitHub Actions**

Aplicação para importar leituras de energia e visualizar consumo e estimativas demonstrativas de emissões.

- API REST autenticada, isolamento por usuário e importação atômica de CSV.
- Dashboard com KPIs, série diária, filtros, alertas e alternativa acessível em tabela.
- Especificação OpenAPI, testes no frontend e backend e CI.

**Status:** MVP de portfólio com modo demonstrativo. [Abrir a demo](https://strong-luck-production-00b9.up.railway.app/).
